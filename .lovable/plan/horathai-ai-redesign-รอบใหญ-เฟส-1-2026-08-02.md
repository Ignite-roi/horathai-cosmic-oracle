# Horathai AI — Redesign รอบใหญ่ (เฟส 1)

เป้าหมายรอบนี้: ยกระดับ "ภาพรวมทั้งแอป" ให้เป็นระดับ Apple Vision Pro / Tesla — ระบบดีไซน์ใหม่, พื้นหลังจักรวาลมีชีวิต, พื้นผิวกระจก-ทอง, การเคลื่อนไหวแบบภาพยนตร์ และเปลี่ยนหัวใจการคำนวณจาก mock seed เป็นการคำนวณดวงจริง พร้อมเปิด Lovable Cloud รองรับโปรไฟล์/ทดลองใช้ฟรี 30 วัน

ฟีเจอร์ใหญ่ที่เหลือ (Time Machine, Destiny Timeline, Voice, ท้องฟ้าวันเกิด, วินาทีดาวย้าย, LINE Rich Menu) จะทำเป็นเฟสถัดไปบนฐานนี้ — เฟสนี้วางโครงข้อมูลและ UI ให้รองรับไว้ล่วงหน้า

## 1. ระบบดีไซน์ใหม่ "Obsidian & Gold"

- โทน: ดำอ็อบซิเดียน + ม่วงเนบิวลา + ทองแท้ (OKLCH tokens ใน `src/styles.css`) ไม่มีสีฮาร์ดโค้ดในคอมโพเนนต์
- พื้นผิว: กระจกหลายชั้น (glass-1/2/3), ขอบทองบาง, เงาลึกแบบ elevation, noise overlay บาง ๆ กันแบนดิ้ง
- ตัวอักษร: Cinzel/หัวข้อระดับพรีเมียม + Noto Sans Thai อ่านง่ายบนมือถือ พร้อมสเกลชัดเจน
- โมชัน: สปริงชุดเดียวใช้ทั้งแอป, page transition แบบ depth, ปุ่มมี press/haptic feel, respect `prefers-reduced-motion`
- แถบนำทางล่างออกแบบใหม่: เกาะกระจกลอย มีไฟทองใต้ไอคอน active และ label ไทย

## 2. จักรวาลมีชีวิต (Live Cosmic Background)

- ระบบพื้นหลังกลางตัวเดียว เปลี่ยนตาม: ช่วงเวลาของวัน, ข้างขึ้นข้างแรม, ธาตุลัคนา, หน้าที่กำลังเปิด
- 3 ระดับคุณภาพตาม Performance Setting: **Auto / Full 3D / ประหยัดแบตเตอรี่**
  - Full 3D: WebGL starfield + เนบิวลา
  - Auto: ตรวจ device (deviceMemory, hardwareConcurrency, FPS probe) แล้วเลือกให้
  - Battery Saver: CSS gradient + canvas เบา ๆ ไม่มี WebGL
- หยุดอนิเมชันเมื่อแท็บอยู่เบื้องหลัง, ลดงาน GPU ระหว่างสกรอลล์, คุมคอนทราสต์ให้ผ่านมาตรฐานเสมอ

## 3. หน้าจอที่ออกแบบใหม่

- **หน้าแรก**: Hero การ์ดเหตุการณ์ดาวสำคัญของวันนี้ (ไม่ใช่การ์ดคะแนนธรรมดา), วงแหวนคะแนน 5 ด้านแบบใหม่, เช็คอิน/สตรีค, สถานะทดลองใช้ฟรีพร้อมแถบความคืบหน้า
- **ผังดวง (จักรวาลดวงชะตา 3 มิติ)**: เขียนวงล้อใหม่ทั้งหมด
  - แกนกลาง: ลัคนา + ชื่อราศีไทย + อวตาร/อักษรย่อผู้ใช้
  - วงใน 12 ราศีไทย, วงกลาง 12 ภพ (ตนุ…วินาศ), วงนอกดาวกำเนิด + ดาวจร แยกรูปลักษณ์ชัดเจน
  - เลขดาวไทย ๑–๙, ดาวพักร์เดินถอย, ความสว่าง = กำลังอิทธิพล, เส้นมุมสัมพันธ์ (เปิด/ปิดได้)
  - ตัวกรอง: กำเนิด / จร / ทั้งคู่ · ดาวหลัก / ทั้งหมด · แสดงมุม
  - กล้อง: ออโต้ออร์บิท, ลากหมุน, พินช์ซูม, รีเซ็ต · แตะดาวเพื่อโฟกัสและเปิดชีตข้อมูลเต็ม (ราศี ภพ องศา-ลิปดา พักร์ ความสัมพันธ์กับดาวกำเนิด ช่วงเวลา)
  - มีรายการ 2 มิติใต้ภาพ อ่านได้ครบทุกข้อมูลสำหรับ accessibility และเครื่องสเปกต่ำ
- **ดาวย้าย**: การ์ดเปรียบเทียบ ก่อน/หลัง พร้อมเหตุผลจาก rule engine (ไม่ให้ AI แต่งเอง)
- **โหรา AI**: แชทดีไซน์ใหม่ ใช้ Lovable AI (Gemini) ตอบโดยรับ "ข้อเท็จจริงดวง" จากเซิร์ฟเวอร์เป็นบริบท
- **พรีเมียม**: หน้าแพ็กเกจใหม่ + สถานะทดลองใช้ฟรี 30 วัน
- **ตั้งค่า**: โหมดประสิทธิภาพ, ลดการเคลื่อนไหว, ข้อมูลวันเกิด

## 4. คำนวณดวงจริง (แทน mock)

- สร้าง engine ฝั่งเซิร์ฟเวอร์: ตำแหน่งดวงอาทิตย์/จันทร์/ดาวเคราะห์จากสูตรดาราศาสตร์ (VSOP87 แบบย่อ / Meeus) → แปลงเป็นระบบนิรายนะด้วยอายนางศ (Lahiri) เพื่อให้ตรงหลักไทย พร้อมราหู/เกตุ และการตรวจพักร์
- คำนวณลัคนาและเรือนชะตาจากวัน-เวลา-พิกัดเกิด (ต้องเก็บพิกัดจังหวัด)
- Rule engine โปร่งใส: มุมสัมพันธ์ + ตำแหน่งภพ → คะแนน 6 ด้าน (การงาน เงิน ความรัก สุขภาพ ครอบครัว คู่ครอง) พร้อม "เหตุผล" เป็นข้อความไทยที่อ้างดาว/ภพ/มุมได้จริง
- ฝั่งหน้าจอไม่คำนวณดวงเอง — เรียกผ่าน server function อย่างเดียว มี cache ต่อวัน

## 5. Lovable Cloud (เปิดในรอบนี้)

ตาราง: `profiles` (ข้อมูลเกิด + พิกัด + การตั้งค่า), `subscriptions`, `trials`, `entitlements`, `trial_events`, `plan_features`, `saved_periods`
- RLS ผูกกับผู้ใช้ทุกตาราง + GRANT ครบ
- ตรวจสิทธิ์ (entitlement) ฝั่งเซิร์ฟเวอร์ ไม่เชื่อฝั่งหน้าจอ
- ทดลองใช้ฟรี 30 วัน: เริ่มเมื่อกรอกข้อมูลเกิดครบและกดปุ่มเอง, แสดงวันเริ่ม-วันหมดชัดเจน, หมดแล้วลดเป็น Free โดยไม่ลบข้อมูล
- เข้าสู่ระบบด้วยอีเมล/รหัสผ่าน + Google ไปก่อน (LINE login เพิ่มเมื่อได้ LIFF ID)

## 6. เลื่อนไปเฟสถัดไป

Time Travel Slider · Destiny Timeline 3D · โหรา AI เสียงไทย · ท้องฟ้าคืนที่คุณเกิด · วินาทีดาวย้าย (ซีเควนซ์ 5 ฉาก) · LINE Dynamic Rich Menu + แจ้งเตือน (รอ Channel token/LIFF ID)

## รายละเอียดทางเทคนิค

- TanStack Start + React 19; 3D ผ่าน R3F/Drei โหลดแบบ lazy เฉพาะหน้าที่ต้องใช้ ไม่โหลดตอนเปิดแอป
- Capability detection + คุณภาพ 3 ระดับ, instancing สำหรับดาว/อนุภาค, จำกัด dpr, ปิด bloom แรง ๆ
- ข้อมูลดวงทั้งหมดผ่าน `createServerFn` (`src/lib/astro.functions.ts`) + `*.server.ts` สำหรับ engine; แคชด้วย TanStack Query
- State ผู้ใช้: Zustand เดิม ซิงก์กับตารางฝั่ง Cloud
- ทุกหน้ามี head() เฉพาะตัว, สถานะ loading/empty/error/offline ครบ
